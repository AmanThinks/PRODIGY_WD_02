# PRODIGY_WD_02 – Stopwatch Web Application

This project is part of my **Web Development Internship at Prodigy InfoTech**.

## 🔹 Task Description
Developed a fully functional stopwatch web application with start, pause, reset, and lap features using JavaScript.

## 🔹 Technologies Used
- HTML5
- CSS3
- JavaScript

## 🔹 Features
- Start / Pause / Reset functionality
- Lap time recording
- Smooth UI animations
- Responsive and user-friendly design

## 🔹 Learning Outcomes
- JavaScript timing functions (setInterval, clearInterval)
- DOM manipulation
- Event handling
- UI/UX enhancement using CSS animations
